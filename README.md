# 문자열 덧셈 계산기

## 구현할 기능 목록

### 1. 문자열 입력 받기

- [x]  문자열 입력 받기

### 2. 구문자 등록하기

- [x]  기본 구문자 (쉼표, 콜론) 등록하기
- [x]  커스텀 구문자 유무 확인하기
- [x]  커스텀 구문자 등록하기

### 3. 문자열 뽑아내기

- [x]  문자열에서 구분자 제거하기
- [x]  커스텀 구문자가 있는 경우 문자열 앞부분의 "//”와 "\n" 제거하기

### 4. 유효한 입력 값인지 확인하기

- 유효하지 않은 값 입력 케이스
  - [x] 숫자 외 문자가 포함되어 있는 경우
  - [ ] 구분자 앞 이나 뒤에 숫자가 없는 경우
  - [ ] 구분자가 연속으로 등장하는 경우
  - [ ] 커스텀 구분자 입력 시 "//" 으로 시작하지 않는 경우
  - [ ] 커스텀 구분자 입력 시 "\n" 으로 끝나지 않는 경우
- [ ]  잘못된 값일 경우  IllegalArgumentException 예외 처리 후 종료하기

### 5. 덧셈 계산하기

- [x]  필터링된 문자열 순회 후 더하기

### 6. 결과 출력하기

- [x]  덧셈 계산의 결과를 사용자에게 출력하기
